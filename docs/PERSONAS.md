# 麦麦人格图鉴（McPersona）

`mcctl whoami` 通过 6 道二选一题，把你映射到 8 型麦麦人格之一。人格不是娱乐标签而已——每型都对应一套**可计算的营养 / 口味 / 社交权重**与一份**本命餐**，直接驱动 `mcctl decide` 的配餐引擎。

## 计分原理

- 每题两个选项，选项对若干人格给 1~2 分；6 题答完累加，最高分即你的人格（平局按图鉴顺序稳定取值）。
- 单元测试枚举了全部 2⁶=64 种作答，保证 **8 型都能被鉴定出来**（题库具备区分度）。
- 人格的 `weights` 被转成配餐约束：热量倾向（low/mid/high）、是否高蛋白优先、嗜辣、嗜甜、早餐、性价比 / 猎奇 / 社交系数；再叠加本命餐码 `signature_meal` 与偏好标签 `prefer_tags` 加权。

### BIGS · 巨无霸本霸
- 口号：面包夹山河，一顿管八小时。
- 权重：高热量、高蛋白优先、社交 0.45、低猎奇；偏好标签：招牌 / 经典 / 牛肉 / 人气。
- 命定命令：`mcctl decide -p BIGS`

### FITA · 板烧修行者
- 口号：板烧去酱，可乐换零，人生也要做减法。
- 权重：低热量、高蛋白优先、极度自律；偏好标签：高蛋白 / 低脂 / 低卡 / 健康 / 健身友好；饮品优先水 / 黑咖 / 零度 / 牛奶。
- 命定命令：`mcctl diet --kcal 600`

### SPCY · 麦辣亡命徒
- 口号：不辣不欢，不新不点，平淡是原罪。
- 权重：高热量、嗜辣、猎奇 0.95；偏好标签：辣 / 新品 / 人气。
- 命定命令：`mcctl decide -p SPCY`

### SWEET · 麦旋风甜心
- 口号：正餐只是铺垫，甜品才是正文。
- 权重：中热量、嗜甜、社交 0.55；甜点 + 甜饮触发"快乐加倍"；偏好标签：甜 / 冰。
- 命定命令：`mcctl decide -p SWEET`

### EARL · 麦满分绅士
- 口号：早起的人，才有资格优雅地咬下第一口麦满分。
- 权重：早餐时段、规律、咖啡续命；偏好标签：早餐 / 咖啡。
- 命定命令：`mcctl decide -p EARL --breakfast`

### NITE · 麦夜骑士
- 口号：天快亮了，而我的麦乐送刚到。
- 权重：高热量、嗜辣、夜宵补给；偏好标签：夜宵 / 鸡肉 / 人气。
- 命定命令：`mcctl decide -p NITE`

### SQUAD · 麦乐送团长
- 口号：一个人吃是快餐，一群人吃是麦门团建。
- 权重：高热量、性价比 0.55、社交 0.95；偏好标签：分享装 / 人气；配餐按人数聚合分享装。
- 命定命令：`mcctl decide -p SQUAD --people 6`

### LOYT · 麦门省钱主教
- 口号：没有券的订单是不完整的，省到就是赚到。
- 权重：中热量、性价比 0.95；偏好标签：性价比；与 `mcctl save` 省钱引擎天然契合。
- 命定命令：`mcctl save`

## 配餐打分如何体现人格

- **控卡模式（FITA）**：超热量硬惩罚；高蛋白加分、低脂低钠加分、健康饮品加分；严格不超热量上限。
- **非控卡模式**：热量贴合目标值为主，叠加嗜辣 / 甜品满足 / 猎奇新品 / 性价比 / 管饱 / 早餐咖啡 / 搭配完整等软标签。
- **本命餐加权**：命中本命主餐 +10、本命搭配 +4/件、偏好标签 +2.5/个，让结果既有"理性最优"又有"情感辨识度"。
- **硬约束优先于人格**：预算、忌口（如 `--no-spicy`）、时段、人数始终不可违反；在此前提下人格才决定风格。

> 营养相关输出仅供参考，不构成医疗 / 营养建议；具体餐品与营养数据以麦当劳官方渠道实时结果为准。
