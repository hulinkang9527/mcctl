    不只是测试，它是一套真能下单的命令行
    
      
    
        
    🃏
    mcctl whoami
    8 型麦麦人格测试，生成可分享麦籍卡。
    
        
    🍱
    mcctl decide
    按人格 / 热量 / 蛋白 / 预算 / 忌口 / 人数，组合搜索命定套餐。
    
        
    💸
    mcctl save
    一键领券、逐券试算、凑单与免配送费，给你真实到手价。
    
        
    🛒
    mcctl order
    到店 / 外送下单闭环，默认演练、二次确认，跳转官方支付。
    
        
    🎁
    mcctl points
    积分总览、商城兑换、抽奖（附理性提示）、活动日历、派对预约。
    
        
    🔌
    33 MCP Tools
    官方 MCP 全量工具真实接入；无 Token 也能离线 Mock 完整体验。
